ℹ️ Factory & Singleton in Action

When you click Add Product, the following takes place:

  1. Factory Invocation: ProductFactory.createProduct(category, id, name, price, stock) creates a clean specialized product object.
  2. Singleton Access: The product is saved into InventoryManager.getInstance(), guaranteeing unified state.
  3. Reactive Updates: The Dashboard and Inventory tables automatically refresh their counts.

Design Patterns Used

Real-world implementation of GoF Design Patterns in JavaScript

🏭

Factory Pattern

Creates different product objects.

How it works: Instead of invoking specialized product constructors directly in UI forms, the client delegates creation to ProductFactory.createProduct(category, id, name, price, stock). 

// Example from app.js:
ProductFactory.createProduct(
  "food",
  "P001",
  "Pancit Canton",
  15,
  50
);
In this application:
  • Instantiates proper subclasses: FoodProduct, BeverageProduct, PersonalCareProduct, HouseholdProduct, SchoolSupplyProduct.
  • Encapsulates category attributes (icons, descriptions) in one location.
🏛️

Singleton Pattern

Maintains one central inventory manager.

How it works: Ensures only ONE instance of InventoryManager exists across the entire app. Any call to InventoryManager.getInstance() returns the identical memory reference. 

// Example from app.js:
const inventory = InventoryManager.getInstance();
const inventory2 = InventoryManager.getInstance();
console.log(inventory === inventory2); // true
Why it's essential for Inventory:
  • A retail store has only one physical stockroom.
  • Prevents desynchronized stock counts between Dashboard, Tables, and Checkout.
  • Provides a single source of truth for all additions, sales, and restocking.
🎯

Strategy Pattern

Allows different discount strategies to be selected.

How it works: Encapsulates different discount algorithms into separate strategy classes (RegularDiscountStrategy, StudentDiscountStrategy, BulkDiscountStrategy) sharing a common interface calculateDiscount(amount). 

// Example from app.js:
checkout.setDiscountStrategy(new StudentDiscountStrategy());
const discount = checkout.calculateDiscount(subtotal);
In this application:
  • Regular Customer: 0% discount.
  • Student Discount: 5% discount (amount * 0.05).
  • Bulk Purchase: 10% discount (amount * 0.10).
  • The Checkout logic remains unchanged when switching algorithms.
